# Icon concept

The original concept was generated with the built-in image generation tool. The shipped extension icon is `assets/icon.png`; the original draft file is not part of the repository.

Both READMEs use `docs/images/logo.png`, a 96 px PNG derived from the shipped icon, with standard Markdown image syntax so the offline renderer can display it. Regenerate this asset and the static badges with `node scripts/readme-assets.mjs` after building. The badges are rendered from text and CSS; they do not request remote badge services.

## Prompt

Use case: logo-brand. Asset type: square VS Code extension icon for Markdown to PDF. Design one polished, exceptionally simple monoline symbol, not a presentation board. Centered document outline with a small folded upper-right corner; inside the document a simple geometric M made from four clean strokes; a compact arrow exits the lower-right edge pointing right to suggest export. Keep the document and arrow visually integrated, uncluttered, balanced. Uniform moderately bold strokes, softly rounded caps and joins, perfect flat vector-like geometry, generous negative space. Near-black navy document and M, a muted blue export arrow, on a solid clean white square background. Readable at 32px. No words, no PDF lettering, no captions, no border frame, no gradient, no shadows, no 3D, no mockup, no decorative marks. Square 1024x1024 composition, symbol occupies about 65 percent of canvas.
